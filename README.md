# Legal RAG Assistant

## Project Overview
Legal RAG Assistant is an AI-powered legal intelligence system that uses Retrieval-Augmented Generation (RAG) to answer legal queries from a legal knowledge base.

## Features
- Legal document search
- ChromaDB vector database
- Sentence Transformer embeddings
- LangChain integration
- Ollama Llama 3.2 support
- Interactive Streamlit dashboard
- RAG analytics
- Knowledge base visualization

## Tech Stack
- Python
- Streamlit
- ChromaDB
- LangChain
- Ollama
- Sentence Transformers
- Plotly

## How to Run

1. Clone repository

  git clone <repo-url>

2. Install dependencies

  pip install -r requirements.txt

3. Run application

  streamlit run src/streamlit_app/app.py
